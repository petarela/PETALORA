# PETALORA — Free Flower Shop Website

A responsive static website for PETALORA | Flowers & Gifts.

## Files
- index.html — main website
- style.css — design and responsive layout
- script.js — menu + WhatsApp order system
- assets/logo.png — PETALORA profile/logo
- assets/cover.png — PETALORA cover/banner
- assets/bouquet-signature.png — bouquet image

## IMPORTANT: Add your WhatsApp number
Open `script.js` and change:
`const WHATSAPP_NUMBER = "8801XXXXXXXXX";`

Example:
`const WHATSAPP_NUMBER = "8801712345678";`

Use the international number without `+`, spaces or dashes.

## Free publishing
You can publish this as a static site using GitHub Pages, Netlify, Cloudflare Pages, or another free static host.

No paid backend is required for the basic WhatsApp-order version.

## Customization
Change product names/prices in `index.html`.
Change colors at the top of `style.css`.
Replace the contact details in the footer.
